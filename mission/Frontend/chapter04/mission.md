1. 북마크 상태를 Zustand로 공유하기
   bookmark-store.ts에 북마크한 영화 ID 배열과 추가·제거 action(toggleBookmark)을 담은 Zustand store를 만들었다.
   목록, 검색, 상세 화면이 모두 같은 store를 사용하도록 연결했다. 화면마다 useState로 따로 관리하던 북마크 상태는 제거했다.
   검색 결과 카드에는 북마크 버튼이 없어서 새로 추가했다.
   한 화면에서 북마크를 추가하거나 해제하면 다른 화면에서도 같은 결과가 보이는 것을 확인했다.
   화면	확인 내용
   목록 → 검색, 상세	목록에서 북마크한 영화가 검색과 상세에서도 북마크 상태로 표시된다.
   상세 → 목록, 검색	상세에서 해제하면 목록과 검색에서도 해제된다.
   검색 → 목록, 상세	검색에서 북마크하면 목록과 상세에도 반영된다.
2. 북마크 상태를 Web Storage에 유지하기
   Zustand의 persist로 store의 북마크 ID 배열을 localStorage에 저장하고, 앱을 다시 열면 복원되도록 했다.
   저장 key는 umcine-bookmark-store이며, 저장할 값은 북마크 ID 배열만 골라서 저장했다.
   새로고침과 브라우저 재실행 뒤에도 북마크 상태가 유지되는 것을 확인했다.
   Application 패널에서 umcine-bookmark-store의 저장값(bookmarkedMovieIds)을 확인했다.
   저장값을 지우고 새로고침하면 북마크가 모두 해제된 초기 빈 상태로 돌아오는 것을 확인했다.
   pnpm build를 실행해 오류 없이 빌드되는 것을 확인했다.
3. 추가로 수정한 내용
   상세 페이지를 Figma에 맞춰 수정했다. 평점 패널의 간격과 별점 칸을 반영했다.
   상세 페이지의 북마크 버튼 색을 목록과 통일했다.
   헤더에서 현재 화면에 맞는 메뉴(영화 또는 검색)에 굵은 검은 글씨와 밑줄이 나오도록 했다. 영화 상세 화면에서도 영화에 밑줄이 유지된다.
